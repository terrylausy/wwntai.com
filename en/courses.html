dexterous hands ROS SDK Tiered CurriculumSystem

WWNT Robotics · based on LinkerHand ROS SDK a tiered curriculum for vocational, undergraduate, and graduate levels. Built on the full LinkerHand ROS1/ROS2 SDK and wwntAI integration, delivering a three-tier standardized dexterous-hand teaching system.

SDK reference:LinkerHand ROS SDK docs | View dexterous hand details

Curriculum Positioning

Hardware foundation

  • • Full LinkerHand line: O7/L6/L10/L16/L20/L25, spanning low-to-high DOF
  • • wwntAI unified teaching platform, sim system, and training benches

Software base

  • • Native LinkerHand ROS SDK (ROS1 Noetic / ROS2 Humble)
  • • Reuse 100+ official open-source examples plus wwntAI teaching wrappers

Tiered training logic

  • • Vocational:Operations + basic programming → equipment debugging and line integration roles
  • • Undergraduate:ROS + hand-eye coordination + force-tactile perception → robot system development
  • • Graduate:Embodied AI algorithms + imitation learning + grasping models → research and competitions
1

Vocational / Associate: "Bionic Dexterous Hand Basic Training"

48 hours · industrial robotics / mechatronics

Objectives:Master dexterous hand assembly, GUI control, Python basics, and industrial grasping to debug devices and develop simple automation stations.

Hardware:L6/O7 low-cost hands, desktop bench, wwntAI visual control software

Module 1: Hardware & Environment Setup (8h)

  • • LinkerHand linkage/tendon/direct-drive teardown; DOF, servo, e-skin, fingertip sensor principles
  • • Ubuntu install, ROS1 setup, LinkerHand SDK source pull and build
  • • setting.yaml config, left/right hand matching, CAN fault diagnosis
  • Assessment:Independently start the SDK, run comms self-check, and troubleshoot faults

Module 2: GUI Control (12h)→ SDK 0002-gui_control

  • • GUI sliders for single-joint control and five-finger pose adjustment
  • • Save waypoints, replay poses, and record gesture sequences
  • • Group labs: fist, spread, pinch, and wave gestures
  • Integrated task:Build a product-display gesture flow, replayable via GUI in one click

Module 3: Python Basics (16h)→ Python L20 basic examples

  • • 0102-gesture-Show-OK: OK gesture program and speed tuning
  • • 0103-gesture-Show-Surround-Index-Finger: index rotation
  • • 0104-gesture-Show-Wave: four-finger wave loop
  • • 0106-gesture-Loop: cyclic grasp/release
  • • 0101-lipcontroller: tactile-triggered pinch (flexible materials)

Module 4: Industrial Grasping (12h)

  • • Force sensor reading (0003) to detect material presence by grip force
  • • Speed and current tuning (0004/0005/0006/0007) for soft/hard materials
  • Final project:A sorting station — the hand auto-recognizes, grasps, and sorts materials
Companion resources (self-developed):Lab guides, videos, Python templates, troubleshooting manual, and 1+X skill exam bank
2

Undergraduate: "ROS Dexterous Hand and Hand-Eye Coordination"

64 hours · robotics / automation / AI

Objectives:Master ROS1/ROS2, multimodal fusion, hand-eye coordination, simulation, and teleoperation to independently integrate systems and design courses.

Hardware:L10/L16 hands, PyBullet workstation, monocular camera, wwntAI cluster system

Module 1: ROS & Low-level Driver Dev (16h)

  • • ROS concepts: nodes, topics, services, parameters; SDK architecture
  • • Source study: joint state (0001), force/speed/current reading
  • • Secondary dev: custom topics for real-time five-finger force and position visualization
  • • L25 extension: disable/enable/teleoperation mode switching

Module 2: PyBullet Simulation (12h)→ SDK 0000-PyBullet

  • • Environment setup, virtual hand loading, offline debugging
  • • Sim-real code interop — one program for both environments
  • Lab project:Trajectory planning for grasping irregular objects in simulation

Module 3: Hand-Eye Coordination & Tactile Fusion (16h)

  • • Vision + tactile fusion grasping with RGB camera and fingertip force
  • • Rock-paper-scissors project (0009): vision gesture recognition + hand feedback
  • • Flexible object manipulation: adaptive grip force via tactile feedback

Module 4: Teleoperation & Cluster System (10h)

  • • L25 teleoperation config, motion-capture glove / vision teaching
  • • wwntAI cluster scheduling of multiple hands and teacher-side monitoring

Module 5: Integrated Design Project (10h)

  • • Complete a full ROS project (choose one):A. Service robot display/interaction system / B. Industrial precision assembly hand-eye grasping system
Companion resources:Full PPTs, complete ROS source, simulation guides, design briefs, and exams
3

Graduate / Innovation: "Embodied Dexterous Manipulation & RL"

32 hours · elective / research

Objectives:Use the LinkerHand SDK for imitation learning, grasp generation, and embodied model deployment, supporting theses, competitions, and grants.

Hardware:L20 flagship 21-DOF hand, humanoid robot, GPU workstation, DexScale tactile dataset license

Module 1: Human-Dex Imitation Learning (12h)→ SDK 1001-human-dex

  • • Conda environment, HDF5 data collection node deployment
  • • Human-taught grasping data collection, HIT RL training
  • • Real-robot reproduction and grasp generalization

Module 2: Unidexgrasp Porting (12h)→ SDK 1002-linker_unidexgrasp

  • • Map ShadowHand grasps to Linker L20 joint space
  • • Train and evaluate GraspIPDF, GraspGlow, ContactNet
  • • Grasp visualization and RL dataset generation

Module 3: Integrated Research Project (8h)

  • • Optional directions:
      ① Multimodal tactile-vision LLM dexterous manipulation
      ② Humanoid hand-foot coordinated motion control
      ③ Competition: RoboMaster / bionic robot dexterous algorithm optimization
Companion resources:Algorithm source, dataset license, paper guidance, competition support

Hardware Architecture

Six Hardware Modules

01

Core Compute Module

Raspberry Pi 5 edge terminal with powerful compute and AI inference, supporting Linux/Ubuntu.

02

Computer / Machine Vision Module

Driver-free USB camera supporting AI vision and voice interaction for object detection, face recognition, and more.

03

Voice Processing Module

Plug-and-play USB microphone for speech recognition, synthesis, and voice interaction projects.

04

Embedded Sensor Module

Curtain actuator, LED control, temperature/humidity sensor, fan actuator, and ultrasonic sensor — covering core IoT sensing.

Lab tools and magnetic mounting for quick modular assembly, ideal for demos and hands-on student labs.

02 / PUBLIC REPOSITORIES

Public Repository Details

Low-level SDKs, simulation demos, and algorithm projects — barrier-free for global developers

wwntAI_LinkerHand_Edu

LinkerHand Bionic Dexterous Hand — Standalone Teaching

Apache 2.0

Fully deployable and teachable independent of the robotic arm. Aligned with the upstream linker-bot ecosystem; low-level drivers under Apache 2.0, freely modifiable for commercial use.

CAN/C++/Python SDK ROS2 full-stack Isaac hand simulation Desktop vision grasping Motion-capture glove / VR teleoperation Multimodal dataset collection
Website → Hardware → LinkerHand standalone desktop dexterous hand training kit Repository

wwntAI_OpenArm_Edu

OpenArm Dual-arm Teaching

GPL-3.0

The bare standard gripper completes all required courses; the dexterous hand is an optional add-on. Unrestricted for on-campus use; commercial derivatives must fully open-source their code.

Full-body motion library ROS2 MoveIt2 motion planning Stereo AI defect inspection Web digital twin Voice LLM control Isaac Sim2Real RL Optional_LinkerHand extension
Website → Hardware → OpenArm Standard / Waist-Neck Edition Repository

wwntAI_MiniPI_Plus_Edu

Mini Pi Plus 20-DOF Humanoid Full-stack

GPL-3.0

A 20-DOF humanoid with eight fully independent core teaching modules — an embodied intelligence research platform for undergraduate theses, graduate projects, and innovation competitions.

Full-body motion library Isaac humanoid simulation Sim2Real transfer Offline speech ASR/TTS LLM voice command control Human pose digital twin Compliant drag teaching VLA end-to-end grasping Optional_Dex_Hand extension
Website → Hardware → Mini Pi Plus humanoid Repository

wwntAI_Sim_Twin_Tools

General Simulation · Digital Twin · Sim2Real Toolkit

AGPL-3.0

Common tools across all product lines with no hardware coupling. Unrestricted local offline use; providing services via web/cloud requires fully open-sourcing the code.

Isaac Lab watermark-free recording Web digital twin frontend/backend ONNX/TensorRT/RKNN conversion Pose retargeting algorithms Unified ROS message packages Audio denoising tools
Website → Capabilities → Simulation / Digital Twin / Sim2Real Repository

04 / LEARNING PATHS

Tiered Training Deployment Path

Public code + private courseware, flexible purchasing and course launch

01

Low-cost entry — LinkerHand dexterous hand only

For: freshman mechatronics and AI basic training, no arm needed

Clone: wwntAI_LinkerHand_Edu Clone: wwntAI_Sim_Twin_Tools Apply: Course_Docs → Dexterous Hand curriculum
02

Industrial robot standard teaching — OpenArm dual-arm only

Delete the Optional_LinkerHand directory for pure dual-arm teaching with no dependencies

Clone: wwntAI_OpenArm_Edu Clone: wwntAI_Sim_Twin_Tools Apply: Course_Docs → OpenArm curriculum
03

Humanoid embodied AI research — Mini Pi Plus only

Access full humanoid curriculum lectures, theses, and competition guides

Clone: wwntAI_MiniPI_Plus_Edu Clone: wwntAI_Sim_Twin_Tools Apply: Course_Docs → Humanoid curriculum
04

Embedded AI basics — OpenEmbeddy training kit only

For computer science, embedded, and AI basics; no robot needed

Clone: wwntAI_Sim_Twin_Tools Apply: Course_Docs → OpenEmbeddy curriculum
05

Advanced integrated lab — full hardware set

FULL STACK

Supports dual-arm assembly, humanoid fine manipulation, multimodal VLA grasping, and embedded AI training for advanced theses, competitions, and research.

06 / UNIFIED STANDARDS

Unified Repository Standards

Standardized base files · asset routing · access control

Standardized Base Files

README.md Company entity · website link · hardware adaptation · deployment guide
install_env.sh One-click Ubuntu environment deployment
requirements.txt Complete Python/ROS dependency list
.gitignore Filters videos / datasets / model weights / caches
LICENSE Corresponding license text

Asset Routing

Simulation recordings and data-collection scripts go to public repos; full teaching videos, large datasets, and 3D model packages are not uploaded to GitHub.

Public repos → scripts, code, small demos
Website download center → cloud links (videos / datasets / models)
Private repos → companion courseware assets

Access Control Rules

Public repositories:Open to global users for Clone, Fork, Star, supporting teaching and non-commercial secondary development
Private repositories:Access granted after business review; sharing accounts or leaking materials is prohibited
